# Candidatures

Ce dépôt regroupe les candidatures d'Alban Lopez.

## Organisation prévue

Chaque candidature disposera de son propre dossier :

```text
candidatures/
└── entreprise-poste/
    ├── offre.md
    ├── cv.html
    ├── cv.pdf
    ├── lettre-motivation.md
    ├── lettre-motivation.html
    └── lettre-motivation.pdf
```

Le fichier [`profil_maitre.md`](profil_maitre.md) centralise l'ensemble du parcours, des compétences, des réalisations et des éléments quantifiés. Il constitue la source de référence pour adapter les futurs CV et lettres de motivation.
